Check it yourself — tap each when done

  1. Open the presenter above and refresh once. Pull down to refresh so it picks up the change.
  2. Tap TYPE. You should see exactly one typing box come up with the keyboard — your phone's own. No second box above it.
  3. Type something. More of the card should still be readable than before.
  4. Send it with the send button. It sends, and the box empties — the clear-after-send you just got still works.
  5. Type something, then swipe the keyboard away without sending. Tap TYPE again — your half-typed text should still be there.
  6. Tap TYPE once more to close it. Everything closes normally, same as always.

Whisper Village — Cheat Sheet

Meeting reference · glance-friendly · honest answers only

What it is, in one breath
Whisper Village is a native macOS menu-bar app that turns your voice into text — entirely on-device, no cloud. You hold a hotkey, talk, release, and the transcript pastes at your cursor in whatever app you're in (terminal, editor, email). Built for keyboard-driven power users who want fast, private dictation.
The honest origin (don't hide this)
Whisper Village is a fork of VoiceInk by Pax (@Beingpax). Our README attributes this clearly. Core transcription/hotkey/paste logic is VoiceInk's. We rebranded it, restyled the UI, relicensed it GPL v3, and wired it into the Mullet Town ecosystem. Not a novel invention — a customized, shipped, working tool on a proven open-source base.

Tech stack

Swift 5 + SwiftUI macOS 14+ (Xcode) whisper.cpp (C++ inference) Parakeet via FluidAudio AVAudioEngine SwiftData (local history) UserDefaults (settings) KeyboardShortcuts Sparkle (auto-update) Accessibility / AX API AppKit / Core Audio

Zero servers, zero cloud calls during transcription. Everything runs on the Mac's CPU using quantized Whisper models bundled or downloaded locally.

The big pieces (what's on the whiteboard)

1. Audio capture

Recorder.swift, StreamingRecorder.swift, AudioDeviceManager.swift

Grabs mic input at 16 kHz mono. Handles device changes, levels, pause/resume. Two modes: buffered file recording vs. live streaming for interim preview.

2. Transcription engines

Whisper/LibWhisper.swift, LocalTranscriptionService.swift, ParakeetTranscriptionService.swift

Two pluggable engines behind a TranscriptionModel protocol: whisper.cpp (most accurate, multiple model sizes) or Parakeet (faster, lighter). Whisper context is a Swift actor — thread-safe.

3. Hotkey & paste

HotkeyManager.swift, CursorPaster.swift

Global hotkey (default Fn), configurable. Double-tap for "send it" (paste + Enter), hold-to-record hands-free mode. Paste = copy to clipboard → synthesize ⌘V via CGEvent.

4. UI / menu bar

ContentView.swift, MenuBarView.swift, MenuBarManager.swift

Menu-bar icon is always-on control. Main window has model picker, hotkey editor, history, cumulative stats. Optional floating "notch" shows interim transcription while you talk.

5. Storage & settings

UserDefaultsManager.swift, Models/Transcription.swift

SwiftData (Apple's modern SQLite wrapper) for transcription history. UserDefaults for settings and stats. File system for downloaded model .bins. All local, no sync.

6. Post-processing

WhisperTextFormatter.swift

Strips filler words (uh, um), auto-capitalizes, adds end punctuation, applies user's word-replacement dictionary and prompt hints before pasting.

7. App lifecycle & distribution

WhisperVillage.swift, AppDelegate.swift, scripts/ship-it.sh

SwiftUI @main boot. Requests mic + accessibility permissions. Ships as a DMG. Sparkle polls an appcast.xml on GitHub for updates. Signed with a self-signed cert so permissions persist across updates.

Data flow — what happens when you dictate

  1. User presses hotkey → HotkeyManager global monitor fires → WhisperState.toggleRecording().
  2. Recorder opens the mic at 16 kHz mono, pushes samples into a buffer; UI flips to "recording", meter animates.
  3. Optional: streaming buffer feeds Parakeet for a live interim preview in the notch box.
  4. User releases hotkey → recording stops → buffered samples flushed.
  5. Samples handed to the active engine (whisper.cpp or Parakeet). Engine returns plain text.
  6. Formatter cleans it (capitalize, punctuate, strip fillers, apply word rules).
  7. Text → clipboard → synthesized ⌘V → lands at the cursor in whatever app is focused.
  8. Transcription saved to SwiftData history; cumulative word/session counters bumped in UserDefaults.

Deployment / how it ships

  • No backend. No servers, no databases, no cloud. Distribution-only.
  • Format: Signed .dmg. Users drag app to Applications. First launch may require xattr -cr to clear Gatekeeper quarantine.
  • Builds: scripts/dev.sh for debug; scripts/ship-it.sh <ver> "notes" bumps version, compiles Release, packages DMG, pushes to GitHub, updates appcast.xml.
  • Updates: Sparkle framework reads appcast.xml from GitHub raw URL, offers in-app update, installs on user approval.
  • Permissions required at runtime: microphone, accessibility (to synthesize keystrokes + detect focused app). No network permission needed for transcription.

Likely questions — honest answers you can say aloud

How does the transcription actually work?

Audio is captured at 16 kHz mono. On stop, the samples go to whisper.cpp, which is a C++ port of OpenAI's Whisper model running locally. The model outputs text; we clean it up and paste it. Nothing leaves the device.

Is it using the OpenAI API?

No. It's the open-source Whisper model running on-device via whisper.cpp. There's no API call, no API key, no internet dependency for transcription.

What's the database?

SwiftData — Apple's modern SQLite wrapper. It stores a local transcription history (text, timestamp, model used, word count). No cloud sync.

How does it scale?

It's a single-user desktop app, so "scale" isn't quite the right frame. Per-user performance depends on model size — Whisper Tiny is fast, Whisper Base is the balanced default. Everything runs on the user's CPU.

What about privacy?

Audio never leaves the device. There's no telemetry, no server, no account. That's actually one of the selling points vs. cloud dictation tools.

Why Swift / SwiftUI?

It's a macOS-only app and native is the cleanest path: tight menu-bar integration, native accessibility APIs, native audio stack. Same reason the upstream project chose it.

Did you write all of this?

Honestly — it's a fork of VoiceInk, attributed in the README. I rebranded it, restyled it, relicensed it GPL v3, and shaped it for our ecosystem. Core transcription/hotkey/paste logic is upstream's. That's a totally legitimate way to ship a working tool, and we're open about it.

Can users add their own vocabulary?

Yes — settings has a word-replacement dictionary and a "prompt hints" field that gets passed into Whisper for better context (helpful for jargon, names, acronyms).

How do updates work?

Sparkle framework — industry-standard for macOS. The app polls an appcast.xml on GitHub, downloads, and installs on user approval. Self-signed cert ensures permissions persist across updates.

Whisper.cpp — is that a real thing?

Yes — it's the standard high-performance C++ port of Whisper by Georgi Gerganov (same author as llama.cpp). Huge ecosystem, well-maintained.

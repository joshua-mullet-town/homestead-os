| Capability | Description | Documentation |
|------------|-------------|---------------|
| **Scheduling** | Set alarms, timers, and delayed notifications | `tools/scheduling.md` |

## How to Use This Document

1. When Josh asks you to do something, scan this table
2. If a capability matches, read the linked documentation
3. Follow the instructions in that doc to execute the task
4. If nothing matches, tell Josh you can't do that yet
